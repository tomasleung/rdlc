# Q1 Visualization Specification

## Title

Q1. Is the Program Growing?

## Executive Answer

Historically yes. Recently stable.

## Purpose

Provide visual evidence that:

1. The Foster Program experienced substantial growth between 2006 and 2010.
2. The Foster Program reached peak activity in 2010.
3. Activity has remained relatively stable since 2011.
4. The program is now operating in a mature and stable state.

## Chart Design Rules

✓ Show actual annual values

✓ Highlight 2006, 2010, and 2025

✓ Use smooth line

✓ Use shaded era bands

✓ Display Long-Term CAGR and Recent CAGR

✓ Focus on storytelling rather than showing every value

✗ Do not display all data labels

✗ Do not repeat KPI #1 (109,738)

✗ Do not repeat KPI #2 (+144.6%)

✗ Do not show annual averages

✗ Do not clutter chart with unnecessary annotations
