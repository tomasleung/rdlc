# Mix-Adjustment/Standardization and Concentration Analysis Methods for BI Diagnostics

## What is the exact formula for direct standardization and indirect standardization, and what's the authoritative source?

### Takeaway
Direct standardization applies each group's own category-specific rates to a common/standard category-mix (weights), producing a directly comparable "as-if-same-mix" rate for every group; indirect standardization instead applies one reference set of category-specific rates to each group's own actual category mix, producing an expected count that is compared to the observed count as a ratio (SMR-style). Direct standardization requires category-specific rates for every group being compared; indirect standardization requires only a single reference rate per category plus each group's category-mix counts — which is exactly the tradeoff described in the research objective. The CDC/NCHS methodology and UK Health Knowledge e-learning resource (a standard epidemiology teaching reference) are the two authoritative sources found.

### Cited Findings
- CDC/NCHS direct-method formula: Age-adjusted (directly standardized) rate = Σ(i=1 to n) [ r_i × (p_i / P) ], where r_i = the rate in category i of the population of interest, p_i = the standard population's count in category i, P = Σp_i (total standard population across all categories), and n = number of categories. This is a weighted average of the group's own category-specific rates, using the standard population's category shares as weights. — [CDC/NCHS, Age adjustment](https://www.cdc.gov/nchs/hus/sources-definitions/age-adjustment.htm)
- NCHS currently uses the projected year 2000 U.S. standard population for age-adjusting mortality data and NHANES/NHIS survey estimates (previously used 1940 standard for mortality, 1980 for NHANES, 1970 for NHIS); standard-population weights are proportions summing to 1.0 (e.g., under-1 age group weight ≈ 0.013818). — [CDC/NCHS, Age adjustment](https://www.cdc.gov/nchs/hus/sources-definitions/age-adjustment.htm)
- Comparability caveat (explicit, authoritative): only rates adjusted to the *same* standard population/weighting scheme should be compared to each other; changing the standard changes the resulting differentials (example given: Black-to-White mortality ratio drops from 1.6 under the 1940 standard to 1.4 under the 2000 standard, because the 2000 standard weights older ages more heavily). — [CDC/NCHS, Age adjustment](https://www.cdc.gov/nchs/hus/sources-definitions/age-adjustment.htm)
- UK Health Knowledge e-learning (standard epidemiology teaching source) confirms direct standardization requires "age-specific rates for all populations being compared, plus a defined standard population," and describes the Comparative Mortality Ratio (CMR) — the ratio of two directly standardized rates — as a common summary comparison (worked example: 9.6/7.1 = 1.35). — [Health Knowledge, Standardisation](https://www.healthknowledge.org.uk/e-learning/epidemiology/specialists/standardisation)
- Indirect standardization formula: Expected events E = Σ_i (n_i × r_i), where n_i is the study group's person-count/person-time in category i and r_i is the *reference/standard* population's category-specific rate; the Standardized Mortality/Morbidity Ratio SMR = Observed (O) / Expected (E), conventionally ×100. SMR = 1.0 (or 100) means observed matches expected; >1 means more events than expected given the group's own mix, <1 means fewer. — [Wikipedia, Standardized mortality ratio](https://en.wikipedia.org/wiki/Standardized_mortality_ratio); confirmed independently by [StatsDirect, Indirect Standardization and SMR](https://statsdirect.com/help/rates/smr.htm) and [Health Knowledge, Standardisation](https://www.healthknowledge.org.uk/e-learning/epidemiology/specialists/standardisation)
- Indirect standardization's data requirement is lighter: only the study group's category-mix counts (not category-specific rates) plus a single set of reference category-specific rates and the group's total observed event count. — [Health Knowledge, Standardisation](https://www.healthknowledge.org.uk/e-learning/epidemiology/specialists/standardisation); [MetricGate, Direct vs Indirect Standardization](https://metricgate.com/blogs/direct-vs-indirect-standardization-rates/)
- Important comparability limitation of indirect standardization (SMR): SMRs computed for *different* study populations are not strictly comparable to each other, because each SMR implicitly uses its own population's category-mix as weights (unlike direct standardization, which uses one fixed, shared weighting scheme for all groups). StatsDirect notes this comparison is only valid under an assumption that the ratio of rates between index and reference populations is roughly constant across categories. — [StatsDirect, Indirect Standardization and SMR](https://statsdirect.com/help/rates/smr.htm)
- Worked numeric example (indirect method): in one population, Observed = 54, Expected = 7, SMR ≈ 7.71 (i.e., ~671% of expected); in a second population, Observed = 45, Expected = 20.5, SMR ≈ 2.2. — [OER Africa, EPI5.5 Indirect Standardisation](https://oerafrica.org/FTPFolder/Website%20Materials/Health/Occ%20Health/Module%202%20(Bio_Epi)/Epidemiology/EPIDEMIOLOGY/Standardisation/EPI5-5.htm)
- Confidence intervals for SMR are typically computed via the Poisson distribution, since the method is standardly applied to rare-event counts. — [StatsDirect, Indirect Standardization and SMR](https://statsdirect.com/help/rates/smr.htm) (via search synthesis)

### Inferences
- Translating directly to the BI/foster-centre context: "direct standardization" = compute each centre's utilization rate *per intake type*, then re-weight using a common/reference intake-type mix (e.g., system-wide mix) to get each centre's "as-if-typical-mix" utilization rate — centres become directly comparable on one scale. "Indirect standardization" = apply the system-wide (reference) per-intake-type rate to each centre's own actual intake-type mix to get an "expected" utilization count for that centre, then compare actual vs. expected as a ratio (a centre-level SMR-equivalent) — this avoids needing a reliable per-type rate from every centre.
- The epidemiology framing generalizes cleanly to any compositional confound (geography × category-mix, centre × intake-type-mix, etc.) — the "category" axis doesn't have to be age.

## What's the practical tradeoff in choosing direct vs. indirect when you may not have full category-by-group breakdowns for every group (sparse data / small cells)?

### Takeaway
Direct standardization needs reliable category-specific rates for *every* group being compared, which breaks down when some groups have small/sparse cells per category (unstable rates, high sampling variance); indirect standardization sidesteps this because it only needs each group's category-*mix counts* (denominators) plus one trusted reference rate per category, making it the standard recommended choice when group-level, category-specific rates would otherwise be based on very few events.

### Cited Findings
- "Indirect standardisation is more appropriate for use in studies with small numbers or when the rates are unstable." — [Health Knowledge, Standardisation](https://www.healthknowledge.org.uk/e-learning/epidemiology/specialists/standardisation)
- Direct standardization's main drawback: each stratum/category needs enough events for a stable rate estimate; with sparse cells the category-specific rate itself becomes unreliable, which corrupts the weighted-average result even though the weighting step is simple. — [MetricGate, Age-Adjusted Rate Methods Compared](https://metricgate.com/blogs/age-adjusted-rate-methods-compared/)
- Indirect standardization is "better suited to small or unstable strata," and needs only age/category-specific population (denominator) counts for the study group plus its total observed event count — it borrows the rate information from the reference population instead of estimating it per group. — [MetricGate, Direct vs Indirect Standardization](https://metricgate.com/blogs/direct-vs-indirect-standardization-rates/)
- Indirect standardization (SMR) is also specifically recommended "in situations where age [category] stratification may not be available for the cohort being studied or where strata-specific data are subject to excessive random variability." — [search synthesis of StatsDirect/CASRAI methodology pages] (same underlying claim repeated across [StatsDirect](https://statsdirect.com/help/rates/smr.htm) and [CASRAI SMR guide](https://casrai.org/guides/standardized-mortality-ratio))

### Inferences
- Practical decision rule for BI: if every centre/group has enough volume in every category to trust a group-level, category-specific rate, use direct standardization (it yields a genuinely comparable rate, usable for ranking and differencing). If some centres are small or some intake-type cells are thin, use indirect standardization instead and present results as a ratio of actual-to-expected (an SMR-style index), not as a directly comparable adjusted rate — and avoid comparing SMR-style ratios centre-to-centre without caveats, since each centre's own mix still implicitly weights its own ratio.
- This is the single clearest "if sparse, use indirect" decision criterion in the literature and should be stated plainly to a non-technical stakeholder: "direct standardization treats every group's own rate as trustworthy; indirect only ever trusts one shared rate and just asks whether each group is seeing more or fewer events than that shared rate would predict given its own mix."

### Gaps
- No quantitative guidance was found for exactly how small a cell must be before direct standardization is considered "unreliable" (e.g., a minimum-event-count rule of thumb such as n<5). This would need a dedicated biostatistics methods source (e.g., Rothman's Modern Epidemiology) not retrieved in this pass.

## What is the formula for HHI, what are its conventional interpretation bands, and is it actually appropriate outside market-concentration/antitrust contexts? What are its known limitations?

### Takeaway
HHI = sum of squared market/activity shares (shares expressed in percentage points, range 0–10,000, or as decimal fractions summing to 1, range 0–1); the current (2023) U.S. DOJ/FTC Merger Guidelines define "highly concentrated" as HHI > 1,800 with a presumption of illegality triggered by a post-merger HHI > 1,800 and an increase of more than 100 points (or a >30% share plus >100-point increase) — a tightening from the 2010 Guidelines' 2,500/200-point and 1,500 "unconcentrated" thresholds. HHI is a legitimate general-purpose concentration measure and is used outside antitrust (trade/export concentration, banking systemic-risk/deposit concentration, energy-supplier dependence), but its antitrust interpretation *bands* (1,000/1,800 or 1,500/2,500) are calibrated specifically to competitive-harm thresholds in a defined relevant market and should not be imported uncritically into an unrelated operational context (e.g., "is foster placement concentrated among centres") — doing so borrows a legal/regulatory threshold that was never calibrated for that purpose.

### Cited Findings
- Formula: HHI is calculated by squaring the market share of each firm (or group) and summing the results; with shares in percentage points the index ranges from near 0 (many equal tiny shares) to 10,000 (a single actor with 100%). — [search synthesis of law-firm memos: Paul Weiss, Baker McKenzie, lexplug] and [DOJ, Horizontal Merger Guidelines Appendix 1 on HHI calculation](https://www.justice.gov/atr/appendix-1)
- 2023 DOJ/FTC Merger Guidelines: a market is "highly concentrated" above a post-merger HHI of 1,800 (lowered from 2,500 under the 2010 Guidelines); a merger is presumed to violate the law if it results in a post-merger HHI greater than 1,800 AND increases the HHI by more than 100 points — or alternatively if the merged firm's share exceeds 30% and the HHI increases by more than 100 points (this second, share-based presumption is new in 2023; it did not exist in the 1992/2010/2020 guidelines). — [Paul Weiss, DOJ and FTC Issue Final 2023 Merger Guidelines](https://www.paulweiss.com/insights/client-memos/doj-and-ftc-issue-final-2023-merger-guidelines); corroborated by [Willkie, US Antitrust Agencies Issue Final Merger Guidelines](https://willkie.com/publications/2024/01/us-antitrust-agencies-issue-final-merger-guidelines-confirming-aggressive-approach-to-enforcement)
- 2010-era (now superseded) bands, cited for historical/comparative context: unconcentrated below 1,500; moderately concentrated 1,500–2,500; highly concentrated above 2,500, with the 2010 Guidelines also providing a "safe harbor" (changes under 100 points generally unlikely to raise concerns) that the 2023 Guidelines do not provide. — [multiple law-firm summaries, e.g. Paul Weiss / Dechert / Velaw, cross-checked against each other]; note the widely circulated "<1,000 unconcentrated / 1,000–1,800 moderate / >1,800 highly concentrated" three-band framing could not be confirmed verbatim against DOJ primary text in this research pass — treat the exact lower boundary (1,000 vs. a figure not explicitly restated in 2023 text) as unverified pending direct reading of the primary 2023 Merger Guidelines PDF.
- Known limitation — oversimplification/market-definition sensitivity: HHI results depend heavily on how the "relevant market" (i.e., the universe being shared out) is defined; the same underlying activity can look "unconcentrated" in aggregate while specific sub-segments are dominated by a single actor (a cited example: a retail market looks unconcentrated overall, but its online-shopping and liquor sub-segments are each dominated by one firm). — [FourWeekMBA, Herfindahl-Hirschman Index](https://fourweekmba.com/herfindahl-hirschman-index/)
- Known limitation — structure vs. conduct: HHI measures market/activity *structure* (how shares are distributed) and relies on accurate share data; it does not by itself measure actual competitive behavior, substitutability, or change over time — it is explicitly a screening tool, not an automatic verdict. — [search synthesis of glossary/explainer sources, consistent across multiple]
- Non-antitrust applications exist and are reported (though from a secondary glossary source, not independently verified against a central-bank/agency primary document): export/trade concentration by product or destination, banking supervision for deposit/systemic-risk concentration, energy-security analysis for supplier-country dependence. — [glossary source via search synthesis — flagged as secondary/unverified]
- Explicit statement that HHI gives disproportionate weight to larger shares (because shares are squared), which matters when the operational risk concern is "a single dominant provider" rather than general dispersion. — [glossary source via search synthesis]

### Inferences
- For the BI/foster-centre diagnostic question ("is placement activity concentrated in a few centres"), HHI can be computed (sum of squared centre shares of total volume) as one *diagnostic number*, but the DOJ/FTC numeric bands (1,800/100-point change, or 1,500/2,500) must NOT be presented as "this is concentrated/not concentrated" thresholds to stakeholders — those bands were calibrated for a legal presumption-of-harm test in antitrust enforcement, a different question (is competition harmed in a defined product market) from an operational question (is throughput/outcomes unevenly distributed across our own network). The honest caveat to put in a reference table: "HHI's antitrust bands answer 'could a merger harm competition in this specific legal market'; they do not answer 'is this a business/operational concern' in an unrelated setting — use HHI's *relative* value (compare this quarter's HHI to last quarter's, or this metric's HHI to another metric's) rather than its absolute antitrust-banded verdict."
- HHI is also explicitly a function of *number of groups* (more groups, all else equal, mechanically lowers HHI toward 1/n even without any change in relative evenness) — this wasn't found in a single clean citation but is a direct mathematical consequence of the formula (minimum possible HHI = 1/n when shares are equal) and is implicit in the "equivalent number of firms" (1/HHI) convention mentioned in passing in the search results. Flag this as a known mechanical limitation: comparing HHI for a network of 32 centres against HHI for a market of 4 competitors is not apples-to-apples without normalizing for n.

## How does a Lorenz curve/Gini coefficient differ in interpretation from top-N share and HHI, and when would an analyst prefer one over another for a short stakeholder-facing explanation?

### Takeaway
Top-N share (or cumulative contribution/CRn) answers a concrete, easily-explained question — "what % of total activity do the top N groups account for" — and is the best choice for a single stakeholder-facing headline number; HHI condenses the *entire* share distribution (not just the top N) into one index sensitive to both the number of groups and the evenness among them, useful for tracking a single network's concentration over time but harder to explain intuitively; the Lorenz curve/Gini coefficient describes inequality across the *whole* distribution (not just top vs. rest) and is best as a visual/diagnostic tool for showing the full shape of imbalance, but is more abstract for a lay audience and loses information when two different distributions happen to share one Gini value.

### Cited Findings
- Top-N / CRn method: rank groups descending by share, compute the sum of the top n shares (named "CRn," e.g., CR3, CR5, CR10 in concentration-ratio literature); practitioner guidance explicitly pairs CRn with HHI and with "what share of X drives 80% of Y" (a Pareto check) as complementary views, not substitutes. — [Umbrex, Product Portfolio Concentration](https://umbrex.com/resources/company-analysis/product-management/product-portfolio-concentration/)
- Cumulative contribution / Pareto curve construction method (directly implementable in Power BI/DAX): sort items descending by contribution, compute a running total, express as a running/cumulative percentage of the grand total, and plot cumulative item-share (x-axis) against cumulative value-share (y-axis), anchored at the origin (0,0). — [Power BI community discussion, Cumulative for Contribution of Sales](https://community.fabric.microsoft.com/t5/Desktop/Cumulative-for-Contribution-of-Sales/m-p/1457897); [Pluralsight lab, Identify top-performing products in Power BI](https://www.pluralsight.com/labs/aws/identify-top-performing-products-in-power-bi)
- Gini/Lorenz formal definition: the Lorenz curve plots cumulative population (group) share against cumulative value share; the Gini coefficient G = A / (A + B), where A is the area between the line of perfect equality and the Lorenz curve and B is the area under the Lorenz curve; equivalently G = 1 − 2B when plotted on a unit square. Ranges 0 (perfect equality — every group has an identical share) to 1 (total inequality — one group has everything); sometimes reported ×100. — [RevisionDojo, Calculate/Interpret Gini Coefficient](https://www.revisiondojo.com/student-faq/calculate-interpret-gini-coefficient); [Ryan O'Connell Finance, Gini Coefficient Calculator](https://ryanoconnellfinance.com/calculators/gini-coefficient-calculator/)
- Discrete computational formula for Gini (spreadsheet/DAX-implementable): G = Σ_i Σ_j |x_i − x_j| / (2n²x̄), i.e., the mean absolute difference between all pairs of group values, divided by twice the number of groups squared times the mean value. — [MetricGate, Lorenz Curve](https://metricgate.com/calculator/lorenz-curve)
- Explicit limitation relevant to "which to prefer" guidance: a single Gini number cannot show *where* in the distribution the inequality occurs — two distributions with very different shapes (e.g., one with inequality concentrated at the top, one in the middle) can produce an identical Gini value; Lorenz curves that cross one another cannot be validly ranked by Gini alone and require looking at the curve itself. — [MetricGate, Lorenz Curve](https://metricgate.com/calculator/lorenz-curve)
- Small-sample/small-group-count limitation specific to Gini: a peer-reviewed source (Deltas, *Review of Economics and Statistics*, 2003) finds the Gini coefficient is downward-biased when applied to populations with few units (explicitly including firm-size/concentration measurement in markets with a small number of firms), which has led to misperceptions about concentration trends; a small-sample correction reduces but does not eliminate the bias. — [IDEAS/RePEc citation of Deltas 2003](https://ideas.repec.org/a/tpr/restat/v85y2003i1p226-234.html)
- A Gini-based reformulation of HHI has been proposed in the literature as a "computationally convenient substitute" for the standard HHI in business-concentration measurement, implying the two measures are related (both derived from the same underlying share distribution) but are not interchangeable in interpretation. — [search synthesis citing a Gini-based HHI paper, title/venue not independently confirmed — treat as a secondary/unverified finding]

### Inferences
- For a short stakeholder-facing explanation, prefer **top-N share or the cumulative/Pareto curve** ("the top 5 of our 32 centres handle 61% of all placements") — it directly answers the business question in one sentence and the chart (a Pareto chart with a cumulative line) is self-explanatory to non-technical audiences.
- Prefer **HHI** only as a secondary, trend-over-time diagnostic for the analyst's own use (e.g., "is our network becoming more or less concentrated quarter over quarter") rather than as the headline number for stakeholders, both because it is harder to explain intuitively (a dimensionless index with no natural business-language unit) and because importing antitrust-style absolute bands would be a methodological misuse (see HHI section above). It is well-suited to monitoring *change* in concentration over time within one consistent group-count, less well-suited to a one-off "is this concentrated" verdict against an external absolute threshold.
- Prefer the **Lorenz curve/Gini** when the audience needs to understand the full shape of imbalance across *every* group, not just the top few versus the rest (e.g., "is the imbalance a top-heavy problem or spread broadly uneven across most centres") — but given its abstractness and the small-group-count downward-bias risk (relevant here since the model has only 32 centres), it should be a secondary/analyst-facing visual, with the plain-English headline still carried by top-N share.
- Recommended BI reference-table mapping: "Is activity concentrated in a few centres?" → **top-N share / cumulative Pareto curve** (best fit — direct, intuitive, answers the literal question). "Is this concentration meaningfully comparable to an antitrust/market-power standard?" → **not applicable** without redefining the question in antitrust terms (relevant market, competitive harm) — HHI's legal bands do not transfer. "Is concentration changing over time, holistically?" → **HHI** (single number, good for a trend line, same centre-count needed for valid period-over-period comparison). "What is the full shape of inequality across all centres, not just the top few?" → **Lorenz curve/Gini**, used cautiously given the small-group-count bias.
