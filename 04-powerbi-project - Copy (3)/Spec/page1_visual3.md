# Q3 Visualization Specification

## Title

Q3. What Is Happening Recently?

## Executive Answer

Recent volumes have stabilized around a mature operating range.

## Purpose

Provide visual evidence that:

1. Foster participation has remained relatively stable in recent years.
2. Activity has operated within a narrow range since 2021.
3. The Foster Program is no longer in an expansion phase.
4. Current activity reflects a mature and predictable operating model.

---

## Recommended Visual Type

Column Chart

### Style

- Green theme
- Clean executive presentation
- Focus on stability, not growth
- Highlight 2026 YTD separately from completed years

---

## Visual Design Rules

✓ Show actual annual totals

✓ Highlight 2026 as YTD

✓ Include recent average reference line

✓ Include Recent CAGR

✓ Emphasize stability

✓ Focus on mature operating range

✗ Do not use growth arrows everywhere

✗ Do not focus on YoY momentum

✗ Do not repeat KPI #2 growth numbers

✗ Do not imply active growth
