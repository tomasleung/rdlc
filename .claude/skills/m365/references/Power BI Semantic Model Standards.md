Semantic Model Standards

Every measure requires:

✓ Business Meaning
✓ Description
✓ Display Folder
✓ Format String

Measure Naming:

Business-Friendly
No Technical Abbreviations

Examples:

Recent Average Fostered Animals

NOT

AvgFoster

Display Folder Structure:

Program Growth
Seasonality
Recent Stability
Forecast Outlook
Executive Briefing

Measure Categories:

Business KPI
Supporting KPI
Formatting
Validation
Narrative
Filter

Do not create measures that only support one visual unless they provide reusable business value.
