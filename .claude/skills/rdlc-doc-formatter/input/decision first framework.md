The 7 Analytical Layers
Layer 1: Data

Question:

What happened?

Examples:

Intake count
Foster count
Capacity count

Analysis Type:

Descriptive

Layer 2: Signal Detection

Question:

Did something unusual happen?

Examples:

Capacity spike
Foster decline
Intake surge

Analysis Type:

Descriptive + Statistical Monitoring

Possible Methods:

Normal Approximation
Control Limits
Anomaly Detection
Layer 3: Diagnostic Analysis

Question:

What is related?

Examples:

Foster rate vs intake
Capacity vs transfers

Analysis Type:

Diagnostic

Possible Methods:

Correlation
Segmentation
Drill-through
Layer 4: Driver Discovery

Question:

What is driving it?

Examples:

Why is capacity increasing?
Why do animals remain longer?

Analysis Type:

Predictive

Possible Methods:

Regression
Feature Importance
Trend Analysis
Layer 5: Decision Insight

Question:

What should we focus on?

Examples:

Centre requiring intervention
Program requiring attention

Analysis Type:

Decision Support

Output:

Prioritized opportunities
Recommended focus areas
Layer 6: Action

Question:

What should we do?

Examples:

Increase transfers
Recruit foster homes
Escalate Animal Flow review

Analysis Type:

Prescriptive

Output:

Recommended actions
Layer 7: Outcome

Question:

Did it work?

Examples:

Capacity reduced
Foster participation increased
Placement time decreased

Analysis Type:

Outcome Measurement
