# KPI Measure Usage & Dependency Audit

Generated by walking every visual (values, query projections, and filter
definitions) across the 3 current pages of **Foster Program Historical &
Forecast Baseline** — Foster Program Summary, Current-Year Monitoring,
Methodology — and cross-referencing every measure's own DAX body for
references to other KPI measures and to Date / Lifecycle Era / Forecast
Outlook Axis / Foster Animal Month columns.

**Purpose:** identify which of the 141 measures currently in
`KPI.tmdl` are safe to remove. A measure is only a real deletion candidate
when **both** "Page(s) Used On" and "Used By Other Measures" are empty —
one covers direct visual usage, the other covers DAX-internal dependencies
(a measure with no visual of its own but called from inside another
measure's formula is still load-bearing).

## Notes / caveats

- Dependency detection is regex-based (bracket-reference parsing of each
  measure's DAX text), not a full DAX parser. It should catch the
  overwhelming majority of `[Measure Name]` and `KPI[Measure Name]`
  references, but a measure written in an unusual way (e.g. built through
  `SELECTEDMEASURE()`, a calculation group, or string-concatenated DAX)
  would not be detected and should be spot-checked before deletion.
- "Column/Table Used" only lists references to the 4 non-KPI tables
  (`Date`, `Lifecycle Era`, `Forecast Outlook Axis`, `Foster Animal
  Month`) — it's there to show which of those tables become fully
  unreferenced once unused measures are pruned, not to enumerate every
  KPI-internal reference (that's the "Used By" / dependency columns).
- This audit does not touch or modify `KPI.tmdl` — it's read-only
  analysis. No measures have been removed.
